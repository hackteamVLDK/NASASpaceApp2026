# Task S3: the spoken lines for ASTRA's voice

Repository: ARES-KIDS, a browser Mars-base game for children aged 7-12 (plain ES modules, Node 20+, `npm test`).
Read AGENTS.md and SCENARIO.md Section 1 (ASTRA 6.7 voice guide). You own ONLY: src/ui/spoken-text.js (new),

## Why
Testers said ASTRA talks far too much: her lines are 17-53 words, a new one every ~6 s. The team decided:
- on screen ASTRA shows a very short line (max 4 words; another task writes those);
- ASTRA gets a VOICE (a local text-to-speech model reads her lines aloud; voice can be switched off in Settings);
- what the voice says is a SPOKEN version of each line: shorter than the full SCENARIO text, natural to hear.
The full SCENARIO text stays unchanged (SCENARIO.md is binding and tested; never edit it or
content/data/strings.en.json).

## What to build
src/ui/spoken-text.js exports `SPOKEN` (frozen { lineId: 'text' }) for EVERY line ASTRA can say:
- every `astra.*` id in content/data/strings.en.json;
- every `astra.*` id in the exported `STRINGS` of src/campaign/lives.js, src/campaign/jobs.js,
  src/campaign/choices-data.js (decision callbacks and the follow-up cards' `astra.f*.alert` bodies).
Read the ids from those real sources (do not guess). Skip a line only if it is a pure placeholder/system id; list
any you skip.
Each spoken line:
- 1 or 2 short sentences, at most 15 words in total (aim for 8-12); one idea; the main action or the main fact;
- keeps the science TRUE (simplify, never change the fact; if a number would mislead when rounded, drop it);
- ASTRA's voice: warm, calm, never scary, no death/dying words, never blames, praises effort;
- written for a speech engine: no abbreviations it would misread except "HP" (write "H P"? no: write "health"
  where HP means health), write numbers that matter as words ("thirty-eight percent"), no symbols (%, +, ->, x, /),
  no emoji, no brackets, no "(fiction)" notes; `{placeholders}` from the full line must stay exactly as they are
  (the game fills them, e.g. {delay});
- a line that is already 15 words or fewer and reads well aloud may stay as it is (minus symbols).
tests/spoken-text.test.mjs: coverage of all ids from the sources above; max 15 words; no forbidden words (die,
dead, death, dying, kill, doom, failed, stupid, dumb); no symbols % + -> x / ( ) [ ]; placeholders preserved.
Report: number of lines, a table of the 20 lines of the first 10 minutes of play (tutorial, Sol 1-2):
"id | full text (first 15 words) | spoken", and any line you could not shorten without losing a true fact.
