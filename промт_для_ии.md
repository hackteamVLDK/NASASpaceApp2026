## 3. Сценарий (кратко; источник истины — SCENARIO.md)

- 2042 год, миссия **ARES-KIDS**, база **Ares-1**, кратер **Езеро**. Проводник — ИИ станции **ASTRA 6.7**.
- Старт игры: текстовое интро в стиле Among Us (0–10 с) → кат-сцена посадки (10–24 с) →
  ASTRA выезжает слева → игрок кликает по спящему **Drone #01** → мини-игра `DroneRepairMiniGame`.
- Мир: холст **1920 × 3200**, линия грунта **Y = 1050**. На поверхности: купол-шлюз, пыльные
  солнечные панели, погнутая антенна, холм реголита, 2 засыпанных дрона.
- Под землёй: **левое крыло работает** (Bedroom, Dining Room, Water & Air Life Support),
  **правое крыло недостроено** (Workshop, Research & Comms Lab, Battery & Heating, Rover Garage + Drone #01).
- Состояния: `INTRO_TEXT → DESCENT → TOUCHDOWN → UNDERGROUND_PAN → TUTORIAL_HANDOFF`.
- Компонент `AstraGuidePanel` с props `{ isOpen, message, mood, onClose }`.

## 7. Принятые решения (и почему)

| Решение | Почему |
|---|---|
| Без сборки и зависимостей: чистые ES-модули, Node ≥ 20 | любой в команде запускает сразу; тесты за секунду |
| `src/sim/` ничего не знает об экране | логику можно тестировать и балансировать без арта; арт подключится позже |
| Синхронизация не делает rebase и reset: слияние считается «в стороне» (`git merge-tree`), рабочая папка двигается только fast-forward | ревью Codex показало, что `rebase --abort` может стереть файл, сохранённый во время rebase |
| Нет «лучевой болезни»: при превышении бюджета дозы астронавта отстраняют от работы | честно для таких доз; последствие всё равно видно игроку |
| Даты штормов — из реальных записей NASA 2024 года, но сила на Марсе — игровое значение; игра нигде не говорит «шторм достиг Марса» | детекторы стоят у Земли; иначе было бы ложное утверждение |
| В мире игры 2042 год; реальные записи 2024 года подаются как «повтор паттерна» | чтобы не противоречить сценарию |
| Приказ «в укрытие» = «никого на поверхности»; вся подземная база и есть укрытие, сбор в Dining Room | по сценарию вся база под 5 м грунта |
| Масштаб: 100 единиц мира = 1 м; 5 единиц = 1 арт-пиксель; 4 этажа по 270 единиц | в сценарии этого нет — **предложение**; все числа сценария делятся на 5 |
| Hydroponics bay (теплица) — модуль-**предложение**, в уровне 1 его нет | в сценарии негде выращивать еду; ждём решения команды |

## 10. Грабли, на которые уже наступали

- **Windows + Git Bash:** длинные `node -e '…'` с кавычками ломаются. Сложные правки — через
  инструмент редактирования файлов или через скрипт во временной папке.
- **CRLF:** в репозитории `.gitattributes` приводит всё к LF; тесты синхронизации клонируют с
  `core.autocrlf=false`, иначе появляются «фантомные» изменения.
- **Codex в режиме read-only не может запускать тесты синхронизации** (ему запрещено создавать
  временные папки) — это нормально, не ошибка.
- **Codex-ревью идёт 5–7 минут.** Запускать в фоне и не править проверяемые файлы, пока он работает.
- Инструмент делегирования пишет «working-tree changes during run» — это наши же параллельные правки,
  а не действия Codex.
- **Не коммитить с упоминанием ИИ.** Сообщения коммитов — по делу, на английском.
- **Перед пушем** — `npm run test:sim`. Сообщать только о тех тестах, которые реально запускались.
- Пока идёт работа, в папке могут появляться чужие коммиты (Влад, Павло) — синхронизация сливает их сама;
  после слияния перечитать изменённые ими файлы (`AGENTS.md`, `CLAUDE.md`, `SCENARIO.md`).
